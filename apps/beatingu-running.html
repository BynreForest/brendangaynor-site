About

BeatingU: Running Challenge brings the BeatingU competitive format to running. Players run timed distances of 0.5, 1, 2, 3, 5, or 10 miles, tracked with GPS that keeps working in the background, and post their times to Game Center leaderboards.

Beyond solo runs, version 1 includes real-time head-to-head racing, so two runners can race each other live, wherever they are.

It shares Vision Challenge’s design language with an orange color scheme, and is built on an MVVM architecture with an AI-assisted workflow using Claude Code.

Tech stack

  • Swift
  • SwiftUI
  • MVVM
  • Core Location (background location)
  • GameKit / Game Center
  • Game Center Leaderboards
  • Real-time multiplayer
  • Claude Code (AI-assisted development)
